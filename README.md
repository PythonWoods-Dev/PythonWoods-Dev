## About

I write software that favours **explicit correctness over clever shortcuts**: definitive
fixes instead of workarounds, documented decisions instead of tribal knowledge, and
tooling that can be trusted in CI as much as on a laptop.

Most of my work is in Python, but PythonWoods is a general developer identity and not
every project is tied to a single language.

## Featured project

### 🔍 [Zenzic](https://github.com/PythonWoods-Dev/zenzic)

A static documentation integrity linter. Zenzic analyses documentation sources without
executing them, catching broken references and structural issues before they reach
readers.

## How I work

Every repository follows the same engineering baseline:

- 📐 **Architecture Decision Records** — numbered ADRs document every significant choice
- ⚖️ **REUSE / SPDX** — machine-readable licensing on every file
- 📝 **Conventional Commits** — atomic, readable history
- 🔒 **Security first** — coordinated disclosure through each project's `SECURITY.md`
